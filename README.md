# Carta de aniversário da Sarah 💗

Página em HTML/CSS/JavaScript com o nome SARAH surgindo primeiro em letras neon, saudações aparecendo depois, texto revelado lentamente ao rolar, partículas brilhantes, mensagem secreta e botão de música.

## Abrir no Chrome
1. Extraia a pasta `carta-sarah`.
2. Abra `index.html` no Google Chrome.
3. Clique em **♫ Música: tocar** para ouvir a música enviada por você.

## Publicar grátis no GitHub Pages
1. Entre em https://github.com/new e crie um repositório público chamado `carta-sarah`.
2. Envie o conteúdo desta pasta para a raiz do repositório. `index.html` deve ficar na raiz, junto com a pasta `audio`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
5. Aguarde a publicação. O endereço costuma ser `https://SEU-USUARIO.github.io/carta-sarah/`.

A página não usa bibliotecas externas. O site publicado em repositório público pode ser visto por outras pessoas.


**Trilha sonora:** o site está configurado para tocar `audio/yet-to-come-remix.mp3` pelo botão “Música: tocar/pausar”. O arquivo foi fornecido pelo usuário. Antes de publicar ou distribuir o site com essa faixa, confirme que você tem os direitos ou autorização necessários; a música pode estar sujeita a direitos autorais.
